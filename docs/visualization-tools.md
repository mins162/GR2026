## 5. 한글 폰트 — 어느 도구를 쓰든 따라오는 문제

matplotlib은 기본 폰트에 한글이 없어 라벨이 `□□□`로 나옴.

```python
plt.rcParams['font.family'] = 'AppleGothic'   # macOS
plt.rcParams['font.family'] = 'NanumGothic'   # 서버 (설치 여부 먼저 확인)
plt.rcParams['axes.unicode_minus'] = False    # 음수 부호 깨짐 방지
```

대안 : **그림 안 라벨을 전부 영문으로 통일하고 캡션만 한글로 쓰기.**
`mempool_group`, `GPU route batches` 같은 이름은 어차피 원래 영문이므로,
이러면 폰트 문제 자체가 사라지고 서버에서 뽑든 로컬에서 뽑든 결과가 같음.
